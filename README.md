# WeiToP Homepage

Project homepage for [Faster or Stronger: Towards Flexible Visual Place Recognition via Weighted Aggregation and Token Pruning](https://arxiv.org/abs/2605.20551).

The page contains the publication title, authors, abstract and BibTeX citation. It uses static HTML and CSS and requires no build step.

To preview locally, run this command from the project directory:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000).
